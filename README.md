# Clean Demo — Chrome Extension

Removes `vendorOnboarding.assessmentSummary.trust` from `localStorage` on the current tab. Useful for resetting demo state before a presentation.

## Install

1. Go to the [Releases](../../releases) page and download `clean-demo.zip`
2. Unzip the file
3. Open Chrome and go to `chrome://extensions`
4. Enable **Developer mode** (toggle in the top-right corner)
5. Click **Load unpacked** and select the unzipped folder

## Use

1. Navigate to the demo page
2. Click the **Clean Demo** icon in your Chrome toolbar
3. Click **Delete from localStorage**
4. Refresh the page — the demo is reset

## Uninstall

Go to `chrome://extensions`, find Clean Demo, and click **Remove**.
